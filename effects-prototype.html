INTERACTION GUIDE

CATEGORY DROPDOWN (Row 1)

Opens a sheet listing all effect categories. Each shows a description, or the applied effect name if one is active.

EFFECT DROPDOWN (Row 2)

Opens a sheet listing effects within the selected category. Pick one (mutually exclusive).

MODIFIER TOGGLES (Row 3)

Tap to toggle on/off. Stackable — both can be active at once. These add motion on top of the base effect.

SPEED BAR (Row 4)

Standard segmented bar. Pick one speed.

RESET

Appears when any setting differs from defaults. Restores everything.
